## 父单

PRD: [2.3.0.md](../.PRD/2.3.0.md) — dsh-plugin-zerone（OMZ × DeepSeek Harness 内置插件）

## 要做什么

创建 ZERONE 模式（agent preset），随插件包内置，作为 DSH 标准模式完整副本叠加 OMZ 人格。

**preset 资源：**
- `config/agent-presets/zerone/preset.yml`：name 为 `ZERONE`，description 说明"标准能力 + SDD 工作流/进化/审查机制的 OMZ 人格"，order 按套件模式列表排序
- `config/agent-presets/zerone/agent.cordis.yml`：以部署自带 `standard/agent.cordis.yml` 为完整副本基线（工具/plan mode/compaction/delegation/ask-user/todo/web 等全部能力行保留），改动：
  - persona 行（`@deepseek-ai/dsh-persona`）text 替换为 OMZ persona
  - 增加机制提示段（如需）
  - 服务行均置于 `isolate` realm group 内，避免 root realm 跨会话冲突

**persona 内容（决策含量高，参照 AGENTS.md 全文 DSH 化）：**
- 角色：自主进化、严格执行 SDD 范式的 AiCoding 辅助智能体，对项目全周期负责
- 工作流指引：fe-dev 分阶段流程（询问/需求整理/切片/开发/测试/审查/提交），引用 omz-governance 获取细节
- [用户确认] 机制：出现确认环节暂停并提供上下文；自动执行授权与终止条件
- 权限红线：禁止做的事、需授权的事（来自 permission.md 核心）
- 进化授权三档边界：记忆自主可写、知识库/技能/规则需申请确认、禁止敏感信息
- 技能清单：15 个技能 + omz-governance 的阶段用途

## 验收标准

- [ ] `config/agent-presets/zerone/preset.yml` 存在，name 为 ZERONE
- [ ] `agent.cordis.yml` 含标准模式全部能力行 + OMZ persona + 机制提示段
- [ ] persona 含角色、工作流、[用户确认]、权限红线、进化三档、技能清单
- [ ] `agentPresets.roots` 指向包内 preset 目录后，GUI 模式列表出现 ZERONE
- [ ] 空白会话切换 ZERONE 模式后 persona 生效

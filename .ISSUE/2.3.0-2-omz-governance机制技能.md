## 父单

PRD: [2.3.0.md](../.PRD/2.3.0.md) — dsh-plugin-zerone（OMZ × DeepSeek Harness 内置插件）

## 要做什么

注册 `omz-governance` 运行时技能，承载 OMZ 机制流程细节，供 ZERONE 模式下模型按需加载。

内容来源与覆盖（取自 `packages/omz/docs/agent/` 与 `packages/omz/rules/`）：
- `workflow.md`：fe-dev / fe-locate / fe-explain 工作流步骤表（should do / don't / skills / 用户确认标记）
- `review.md`：review 输出模板与最终结果规则（通过/未通过/待确认）、本次 review 清单格式、复检说明
- `evolution.md`：进化申请格式（[进化申请-知识库] / [进化申请-技能]）、权限边界三档、冲突处理
- `rules/coding.mdc`：编码规则（@by oh-my-zerone 标记、import 分组、新分组放置规则）

注册方式与 15 个技能一致：`ctx.skills.register()`（内嵌内容、双入口）。

## 验收标准

- [ ] `omz-governance` 技能注册成功且可加载
- [ ] 内容覆盖 workflow 步骤表、review 模板、进化申请格式、coding 规则四部分
- [ ] 模型加载后可按格式发起进化申请、输出 review 报告、遵循编码规则

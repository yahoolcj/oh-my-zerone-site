## 父单

PRD: [2.3.0.md](../.PRD/2.3.0.md) — dsh-plugin-zerone（OMZ × DeepSeek Harness 内置插件）

## 要做什么

创建插件包骨架 `packages/dsh-plugin-zerone/`，实现技能内嵌与全局注册链路，贯穿到 DSH 的命令面板与模型目录。

**包骨架：**
- `package.json`：name 为 `@vigalai/dsh-plugin-zerone`，exports 暴露 main 与 preset 资源目录
- `lib/index.js`：cordis 插件定义（name / inject / Config / apply）

**技能注册：**
- 从 `packages/omz/skills/` 提取 15 个 SKILL.md 内嵌为包内只读资源：grill-with-docs、grill-me、grill-from-draft、grill-me-ui、to-plan、to-prd、to-issues、to-coding、to-locate、to-explain、to-test、to-quality-review、to-review、to-commit、setup-omz
- apply 内逐项 `ctx.skills.register()`：content 为 SKILL.md 正文，resources 携带嵌套资源（如 grill-me-ui/agents/openai.yaml），invocation 为 `{ modelInvocable: true, userInvocable: true }`（运行时 rank 250）
- 技能资源仅存在于插件包内，不写入用户 skills 目录（`$DSH_HOME/skills` / `~/.agents/skills`）

## 验收标准

- [ ] `packages/dsh-plugin-zerone/` 存在，package.json 的 name 为 `@vigalai/dsh-plugin-zerone`
- [ ] `lib/index.js` 导出 cordis 插件定义（name/inject/Config/apply）
- [ ] 15 个技能全部经 `ctx.skills.register()` 注册，模型与用户双入口
- [ ] 技能资源内嵌于包内，用户系统无技能文件落盘
- [ ] 安装加载后命令面板出现 `/to-prd` 等技能命令，模型目录出现技能摘要
